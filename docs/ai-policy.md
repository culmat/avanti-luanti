# AI policy of avanti-luanti

avanti-luanti uses AI agents (Claude Code) to help build Luanti mods. The Luanti community holds a wide range of views on generative AI, so this policy aims to make AI use **transparent, accountable and respectful of upstream rules**.

## Rules for mods made with the factory

1. **Disclose honestly.** Every mod carries `.cdb.json` `ai_disclosure`:
   - `ASSISTED`: AI helped write code, and a human reviewed and understands every change. This is the template default.
   - `GENERATED`: substantial code, or any media (textures, sounds, models), was generated by AI.
   - `NONE` only if no generative AI was involved at all.
2. **AI-generated media is allowed, and always disclosed.** Every AI-generated or AI-modified asset is listed in the "AI-generated assets" section of the mod's `LICENSE`, with the tool used. The README states the disclosure too. If the media license requires attribution, list the human contributors as well.
3. **A human is accountable.**
   - Nothing is published without explicit human approval in the session: no ContentDB package or release, no git tag push, no forum post.
   - `/avanti:release` asks before each external step.
4. **Quality over quantity.**
   - A mod is released only when lint is clean and it passes `avanti test` in every game it claims to support.
   - We don't flood ContentDB with near-duplicates or low-effort content (ContentDB rejects "slop").
5. **Right to a name.** The factory checks names against ContentDB before scaffolding and never squats names.

## Rules for contributing upstream ("give back")

1. **Follow each project's policy.**
   - The Luanti engine ([doc/developing/ai_policy.md](https://github.com/luanti-org/luanti/blob/master/doc/developing/ai_policy.md)) forbids "vibe-coded" or autonomous AI contributions, AI-written text in issues, PRs and documentation, and AI-generated media.
   - We treat all luanti-org repositories that way unless their own policy says otherwise.
2. **Agents collect evidence; humans write to humans.** `/avanti:give-back` produces local notes (reproduction steps, log lines, `ldg` findings, a suggested diff). The maintainer files issues and PRs in their own words and discloses significant AI assistance.
3. **Agents never post, comment, open PRs or push to third-party repositories on their own.**
4. **Be a good API citizen.** Identify ourselves (User-Agent), rate-limit, cache, and publish shared data (the nightly luanti-depgraph snapshot) so others don't have to crawl.

## The factory's own code

avanti-luanti and luanti-depgraph are developed with AI assistance and reviewed by the maintainer. That's stated in both READMEs. Contributions to them may use AI assistance if it's disclosed in the PR and the contributor understands the change.
